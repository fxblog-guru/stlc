Agentic QA for Claude Code

From raw docs to release sign-off, run by agents.

One pipeline covers the whole testing lifecycle. Each step is a command, and each command leaves a file you can open and check. It tests the product and never edits it.

          Get started
          
        
          Install, fill one file, run
          
      
          
      
          
        
          1
          Install
          

          pip install git+https://gitlab.com/agentic-fx/cli-afx.git
afx install --setup
afx doctor
          
          
          Start once afx doctor passes.
          
        
          2
          Fill the profile
          

          # PROJECT-PROFILE.md
Test types    api, e2e, unit
Platforms     web, android
Environments  qa, staging
Gates         0 P0 failing
          
          
          The only config file, so the bundle fits any product.
          
        
          3
          Run
          

          /qa-analyze my-feature PROJ-1
/qa-plan    my-feature
/qa-design  my-feature
/qa-script  my-feature
/qa-run     my-feature
/qa-report  my-feature
          
          
          Lost? /qa-help shows what comes next.
