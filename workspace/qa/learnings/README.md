# Lessons — <qa-root>/learnings/

What this suite has learned across runs, one lesson per `LRN-<TOPIC>.md` (CONTRACTS §23). Written by
`/qa-learn` only, after `npm run qa:learn -- check` passes; read by skills through
`npm run qa:learn -- recall --type <t> --module <m> --skill <s>` (an index: title and probe per hit),
then `npm run qa:learn -- show <id> …` for the ones that apply.

A lesson is a habit for next time, cited to the runs, reviews or human statement it came from.
Product facts belong in `wiki/`; product bugs in `defects/`.
